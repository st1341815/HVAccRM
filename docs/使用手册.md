## 1. 登录与账号

- 打开 `http://192.168.11.8:8090`，输入账号密码登录。
- 管理员初始账号：`admin`（密码由部署时设置，请保管好）。
- 忘记密码：由**管理员**在「系统 → 用户管理」中为该账号「重置密码」。
- 账号体系：每个用户有**姓名 + 登录账号 + 角色**，姓名用于全站展示与下拉选择。

**建议**：为每位同事单独建一个账号（而非共用一个 admin），便于分工与审计。

## 2. 建议的业务流程

一条完整的客户旅程大致如下：

1. **建楼盘/房号**（「楼盘/房号」模块）——录入小区、楼栋、单元、房号。
2. **建客户**（「客户」模块）——选楼盘房号，填姓名、手机、微信、意向产品。
3. **建合同**（「合同」模块）——自动生成合同号，选产品类型、合同额，上传纸质合同照片。
4. **登记收款**（「收款」模块）——记录每笔到账与付款截图；退款记负数。
5. **施工跟进**（「施工」模块）——按「上门勘测 → 前期施工 → 后期施工 → 调试验收」四节点推进，拍照留档、完工备注。
6. **成本登记**（「成本」模块）——材料/施工/介绍费等费用归集，看利润。
7. **回款催收**——在「收款 → 欠款预警」里看未收款项。

## 3. 模块说明

### 3.1 首页看板
汇总经营概况：未完成工序、在施工地、可见客户总数、近 30 天新增、未收总额、本月业绩（签约额/已收款/回款率）、Top5 欠款客户、客户来源分布、最新现场照片、未完成工序清单。

### 3.2 客户
- **新建客户**：姓名、手机号、微信、**意向产品**（可多选）、类型、来源、等级、楼盘与房号、负责人。
- **详情页**含多个标签：概况、联系人、合同、收款、施工、成本、照片。
- 支持**全文搜索**（姓名/手机/微信/房号/楼盘名）。
- 删除客户会**连带清理其照片附件**；有合同/收款的客户请谨慎删除。

### 3.3 楼盘 / 房号
- 新建楼盘：**城市 / 区县联动下拉**（默认合肥/包河区，可改），填楼盘名称、开发商、交房日期。
- 楼盘下建**楼栋 + 房号**：单元固定为「1单元 ~ 9单元」下拉。
- 房号支持按楼盘名 / 房号**模糊搜索**。
- 删除楼盘：**挂有客户的楼盘拒绝删除**；空楼盘删除时连带其房号一并删除。

### 3.4 合同
- **合同号自动生成**：`ONE` + 8 位年月日 + 4 位顺数（每年重置），无需手填。
- 必填：客户（对应房号）、**产品类型**（单选）、合同额、优惠（可选）。
- 支持**上传纸质合同照片**（多张），点缩略图可放大查看、左右翻页。
- 详情页可：登记收款、登记退款、添加增项、添加合同明细、查看成本与利润。

### 3.5 收款
- **登记收款**：方式（微信/支付宝/银行转账/对公/现金等）、金额、日期，可附**付款截图**。
- **退款**：金额记负数。
- 口径为「**未收**」（合同额 − 已收 + 增项 − 优惠），无分期计划概念。
- 「欠款预警」页按未收金额排序，方便催收。

### 3.6 成本与利润
- **成本明细**：费用项目（见附录）、金额、日期、备注、**附图**（发票/收据）。
  - 「材料成本」**必须**关联供应商；「施工费用」**必须**关联安装师傅。
- **供应商**：单独维护，登记成本时下拉选择。
- **利润核算**：按合同/客户汇总 收入 − 成本 = 毛利，展示毛利率；可下钻到每个合同。

### 3.7 施工（工序）
- 每个客户建单时自动生成 4 个标准节点：
  **上门勘测 → 前期施工 → 后期施工 → 调试验收**。
- **前置依赖**：上一节点未完成，下一节点不能开工。
- 操作：**开工 / 完工 / 跳过**（跳过必须填原因）。
- **完工备注**：完工时可填写，追加到节点记录。
- **现场照片**：每个节点可上传照片（见 3.8）。
- **视图切换**：按任务列表 / 按客户分组（一个工地一张卡）。
- **快捷筛选**：全部未完成、我负责的。
- **不做计划排期**：系统只记录实际开工/完工日期，不追踪计划工期。

### 3.8 照片
- **上传**：
  - 电脑端：点「🖼 选择图片」选图 → 点「上传」；选图后会显示「已选 N 张：文件名」。
  - 手机端：三个按钮 ——「📷 拍照」（直接调相机，选完自动上传）、「🖼 选择图片」（从相册选）、「上传」。
- **查看**：点缩略图弹出**灯箱**放大；手机**左右滑动**切换、电脑用**← → 方向键**；**点图片**在「适应屏幕 / 2 倍放大」间切换；Esc 或点空白关闭。
- 中键 / Ctrl+单击 / 新标签打开会进入**照片查看页**（带返回、上一张/下一张、查看原图）。
- 相册页可删除照片；照片按内容 Hash 去重，重复上传不会产生冗余文件。

### 3.9 系统管理（仅管理员）
- **用户**：新建用户（姓名/账号/角色）、重置密码、改角色（改角色会强制其重新登录）。
- **权限**：按角色分配权限点、数据范围。
- **工序模板**：增删节点、调整顺序、是否需照片、启用/停用；**在用节点拒绝删除**。
- **备份**：手动触发备份；每日自动备份并保留最近 30 份。
- **审计日志**：记录关键操作（登录、增删改、改密等），便于追责。

## 4. 角色与权限

| 角色 | 说明 | 能做什么 | 数据范围 |
| --- | --- | --- | --- |
| **管理员（店长）** | 全部功能 | 含用户/权限/备份/审计 | 全部客户 |
| **销售** | 客户与收款 | 客户、合同、收款、成本、施工、照片 | 仅自己负责的客户 |
| **设计师** | 看客户+施工 | 看客户、施工、传照片 | 共享给 TA 的客户 |
| **安装工** | 施工执行 | 看施工、传照片 | 仅被指派任务的客户 |
| **财务** | 收款与成本 | 客户、合同、收款、成本 | 全部客户 |

- **金额隔离**：设计师、安装工**看不到金额**（合同额、收款、成本均不显示）。
- 角色权限可在「系统 → 权限」中按需调整。

## 5. 手机端使用

- 直接用手机浏览器访问同一地址，页面自动适配。
- 表格在小屏自动转成「标签 + 值」卡片，方便阅读。
- 施工看板支持**相机直拍**：点 📷 直接拍照并自动上传，适合工地现场记录。
- 顶部导航横滑、筛选条整行堆叠、按钮加高便于点按。

## 6. 常见问题 FAQ

**Q：点「上传」没反应？**
先确认是否**先选了图片**（选图后按钮旁会显示「已选 1 张：xxx.jpg」）。若没选就点上传，会弹「请先选择图片」提示。

**Q：页面还是旧样子 / 新功能没生效？**
浏览器有缓存，按 **Ctrl + Shift + R** 强制刷新（手机端下拉刷新）。

**Q：点图片直接跳到了"裸图片"页，没有返回按钮？**
这是中键/Ctrl+单击/新标签打开的情况，会进入「照片查看页」——该页有「← 返回」和顶部导航。普通左键点图是弹灯箱，不跳页。

**Q：演示数据怎么清掉？**
由管理员在 NAS 上执行：
```bash
docker exec crm python -m scripts.seed_demo --purge
```
演示数据名称都带「演示」字样，可与真实数据区分。

**Q：合同建错了想删？**
目前合同**只能改不能删**（明细/收款可单独删）。如需删除功能请联系管理员反馈。

**Q：楼盘信息（名称/城市）填错了？**
楼盘暂不支持编辑，只能删除重建（会连带房号）。删除前请确认楼盘下没有客户。

**Q：换了手机/电脑登录不了？**
确认在**同一局域网**内；若提示密码错误，联系管理员重置密码。
